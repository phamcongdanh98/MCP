WorkspaceGuard

Kết nối một thư mục cục bộ với MCP, theo quyền bạn chọn.

● Chưa chạy

1. Chọn workspace

Chưa chọn thư mục

MCP chỉ được quyền thao tác trong thư mục này. Hãy dùng một thư mục thử nghiệm khi mới bắt đầu.

2. Chọn quyền truy cập

Chỉ bật khi bạn tin tưởng workflow. Lệnh chạy bằng quyền tài khoản macOS hiện tại.

3. Chạy server

Chọn thư mục trước, sau đó khởi động.

4. Kết nối ChatGPT qua Secure MCP Tunnel

Tunnel giữ MCP ở localhost và tạo kết nối HTTPS đi ra ngoài. Runtime API key được mã hóa bởi hệ điều hành; không được hiển thị lại hoặc đưa vào log.

Chưa có Runtime API key đã lưu.

Khởi động MCP trước khi kết nối Tunnel.

5. Kiểm tra MCP thật

App sẽ kết nối MCP client thật vào server vừa chạy. Ở mode ghi, nó tạo một file tên ngẫu nhiên, đọc lại, rồi chuyển file đó vào trash có thể khôi phục.

  • Khởi động server để bắt đầu kiểm tra.
